Public Site

The public-facing marketing site at myquest.au. It has no authentication requirement. Its primary goals are lead generation (via the quote modal) and brand presentation.

Homepage — index.html

The main landing page. Fully static — no JS data fetching. Loads four scripts: header.js, footer.js (both handle their include components), main.js (scroll animations + stat counters), and quote-modal.js.

Page sections

SectionContent
HeroHeadline, subline, two CTAs ("Get a Free Quote" → opens quote modal, "Learn More" → scrolls to services). Background gradient.
ServicesThree service cards: Residential, Commercial, End of Lease. Each has an icon, title, description, and feature bullet list.
Why UsFour benefit cards (Reliable, Thorough, Eco-Friendly, Insured). Animated stat counters (happy clients, properties cleaned, etc.).
Contact / CTAPhone number, email, service area list, and a final "Get Your Free Quote" CTA button.

SEO

  • Open Graph tags for social sharing
  • Twitter Card metadata
  • JSON-LD LocalBusiness schema (business name, address, phone, service area)
  • ABN: 65 693 175 405

main.js

  • Stat counters: Any element with data-target and class stats__number animates from 0 to the target value when scrolled into view. Uses IntersectionObserver with easing over ~2 seconds. Numbers formatted with en-AU locale (comma separators).
  • Scroll animations: Elements with class animate-on-scroll get is-visible added when they enter the viewport (threshold 0.15, rootMargin -40px). CSS handles the actual animation via transitions on .is-visible.

Header & Footer

The header and footer are loaded as HTML includes via JS on the public site.

header.html + header.js

The header contains the MyQuest logo (SVG inline), desktop navigation (Home, Services, About, Contact, Login, Get Quote), and a mobile hamburger menu with a full-screen overlay.

header.js responsibilities:

  • Adds .is-scrolled to <header> when page is scrolled (triggers background change)
  • Marks the active nav link by matching window.location.pathname
  • Hamburger: opens/closes mobile overlay, traps focus, closes on ESC or nav link click, closes on backdrop click

footer.html

Static footer — no JS. Contains:

  • MyQuest logo + tagline
  • Social links: Facebook, Instagram
  • Quick links column, Contact column (phone: 0400 000 000, email: hello@myquest.au)
  • Service areas list
  • Copyright + ABN

Placeholder contact details: The phone number (0400 000 000) in the footer is a placeholder and should be updated to the real number before going live.

Quote Modal — quote-modal.js

A single-step enquiry form that slides in as a modal overlay. Any element with data-open-quote will open it on click. It POSTs to /api/submit-quote on submission.

Fields

FieldTypeRequired
Full NameText inputYes
MobileTel inputYes
EmailEmail inputYes
SuburbText inputYes
ServicePill buttons (General Clean, Deep Clean, Commercial, Other)Yes — one must be selected
NotesTextareaNo
TurnstileCloudflare widgetYes — auto-validates

Behaviour

  • On open: locks page scroll (sets body { position: fixed } with saved scrollY to prevent jump)
  • On close: restores scroll position. Close via #qm-close button or pressing ESC.
  • Service pills: clicking one deselects others and sets a hidden input value
  • On submit: validates all fields, verifies Turnstile token, POSTs JSON to /api/submit-quote
  • On success: hides form, shows confirmation message, auto-closes after a 5-second countdown
  • On error: shows inline error message, re-enables submit button
  • Turnstile sitekey: 0x4AAAAAADqM-GWUxyG0P402

API call

POST /api/submit-quote
Content-Type: application/json

{
  "full_name": "Jane Smith",
  "phone": "0412345678",
  "email": "jane@example.com",
  "suburb": "Glenelg",
  "services": ["General Clean"],
  "notes": "Weekly preferred",
  "cf-turnstile-response": "<token>"
}

  • On success: builds a mq_session object in sessionStorage with { id, email, name, role, loginTime, lastActivity }

Staff accounts are invitation-only — there is no self-registration. The owner creates accounts via the Settings page, which triggers a Supabase invite email directing staff to set-password.html.

Set Password — set-password.html + set-password.js

Handles two flows that share the same page:

  • Invite flow: New staff clicking the invite email link. The URL contains a Supabase PKCE ?code= parameter. The page exchanges it for a session, then presents a "set your password" form.
  • Password reset flow: Existing staff who requested a reset email. Same URL structure, same page.

Flow

URL with ?code= token
→
exchangeCodeForSession()
or onAuthStateChange
→
Show password form
(8+ chars, confirm)
→
updateUser({ password })
→

dashboard/onboarding.html

Validation

  • Minimum 8 characters
  • Passwords must match
  • 10-second fallback: if no session is resolved (invalid/expired token), shows an "invalid or expired link" state with a link to request a new one
