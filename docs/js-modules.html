JS Modules

Reference for the four shared JavaScript modules loaded on every dashboard page. All are plain IIFE-wrapped scripts that attach to window.MQ. No module system, no bundler.

supabase-client.js

Initialises the shared Supabase client and attaches it to window.MQ.supabase.

What it does

MQ.supabase = window.supabase.createClient(
  'https://mxgvkzyifphucndovypt.supabase.co',
  '<anon key>',
  {
    auth: {
      persistSession: true,    // Auth token stored in localStorage
      autoRefreshToken: true,  // Refreshes JWT before expiry
      detectSessionInUrl: true // Handles invite/reset tokens in URL
    }
  }
)

Notes

  • The anon key is intentionally embedded — it's public. Security relies on RLS policies.
  • detectSessionInUrl: true is needed for the set-password.html invite/reset flow.
  • Loaded before store.js and auth.js — no defer.

store.js

A simple in-memory data cache. Acts as a synchronous source for data that was fetched during auth initialisation, so page scripts don't need to refetch common data.

Exposes MQ.store with four entity stores:

StoreContainsPopulated by
MQ.store.staffAll staff profiles (id, name, email, role, colour, mobile, availability, active)auth.js on every page load
MQ.store.accountsAccount records (id, name, email, role, status)auth.js on every page load
MQ.store.ratesCompany rates object (residential + commercial rates + extras + checklist template)auth.js on every page load
MQ.store.clientsClient records (populated by clients.js only)clients.js

Entity API

Each store has the same interface:

MQ.store.staff.getAll()        // Returns array of all records
MQ.store.staff.getById(id)     // Returns single record or null
MQ.store.staff.save(obj)       // Upsert — updates if id exists, inserts if new
MQ.store.staff.delete(id)      // Removes from in-memory array

Special: MQ.store.rates

Unlike the others, rates is a single-object store (not an array). It uses get() and save(obj): 

var rates = MQ.store.rates.get();  // Returns the full rates object
MQ.store.rates.save({ ...rates, bedroomBase: 50 });  // Merges updates

Important: store is page-session only

The store resets on every full page navigation. It's not a persistent cache — it only prevents redundant fetches within a single page session. Staff/rates data loaded by auth.js is available immediately inside mq:ready handlers without additional fetches.

auth.js

See Dashboard Overview → Auth Flow for the full auth walkthrough. This section covers the public API exposed on window.MQ.

Public API

PropertyTypeDescription
MQ.session Object { id, email, name, role, loginTime, lastActivity }. Set synchronously on fast path (from cache), asynchronously on slow path. May be null before mq:ready fires.
MQ.hasRole(minRole) Function → Boolean Returns true if current user's role level ≥ the required level. E.g. MQ.hasRole('manager') is true for manager and owner.
MQ.onReady(fn) Function Calls fn immediately if auth is already complete, or queues it to be called when mq:ready fires. Preferred over addEventListener('mq:ready', fn) for imperative code.
MQ.messageOfWeek String The current "message of the week" text from company_settings. Empty string if none set.
MQ._ready Boolean Internal flag — true after mq:ready has fired. Do not depend on this directly; use MQ.onReady().

Events dispatched

EventWhen
mq:readyAuth complete, session established, store populated. Safe to read all MQ.* properties.
mq:pageshowbfcache restoration (browser back/forward). Page scripts should reload their data.

ui.js

Shared UI utilities. Loaded with defer — available after DOM is parsed. All utilities live on MQ.ui.

MQ.ui.modal

MQ.ui.modal.open('modal-id')   // Opens modal, locks scroll, traps focus
MQ.ui.modal.close('modal-id')  // Closes modal, restores scroll
MQ.ui.modal.closeAll()         // Closes all open modals

Modals are standard .modal-overlay elements in the DOM. Opening adds .is-open and removes the hidden attribute. Closing reverses both. ESC key and clicking the overlay backdrop close the modal automatically.

HTML shorthand: add data-modal-open="modal-id" to any button to open without JS. Add data-modal-close to close the nearest parent overlay.

MQ.ui.toast

MQ.ui.toast('Message text')              // Success toast (3s)
MQ.ui.toast('Something went wrong', 'error')  // Error toast (3s)
MQ.ui.toast('Saved', 'success', {         // Toast with link (6s)
  href: 'scheduled-jobs.html',
  label: 'View jobs'
})

Toasts appear in a fixed #toast-container in the bottom-right. They auto-dismiss after 3s (6s with a link). Types: success, error, info.

MQ.ui.saving / MQ.ui.saved

A "Saving… / Saved ✓" overlay for form submissions. Shows for at least 1 second.

MQ.ui.saving();          // Shows "Saving…" overlay
await doSomeApiCall();
MQ.ui.saved();           // Transitions to "Saved ✓" then hides after 800ms

MQ.ui.confirmDelete

MQ.ui.confirmDelete('Are you sure? This cannot be undone.', function () {
  // Called only if user clicks OK
  doDelete();
});

Uses native window.confirm(). The message parameter is optional.

Global helpers

escHtml

Defined on window.escHtml in ui.js (and defensively re-defined as a local var inside each page IIFE). Escapes HTML entities to prevent XSS when rendering user-provided data into innerHTML. 

escHtml('<script>alert(1)</script>')
// → '&lt;script&gt;alert(1)&lt;/script&gt;'

Always use escHtml() when inserting user-provided strings (names, addresses, notes) into innerHTML. Never insert raw data directly.

Page JS pattern

Every page-specific JS file follows this structure:

(function () {
  'use strict';

  // Defensive local escHtml in case ui.js loads out of order
  var escHtml = window.escHtml || function (s) {
    return String(s || '').replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/>/g, '&gt;').replace(/"/g, '&quot;');
  };

  // Module-level state
  var data = [];

  // ── Data loading ──────────────────────────────────────
  async function load() {
    var res = await MQ.supabase.from('quote_requests').select('*').eq('status', 'scheduled');
    if (res.error) { console.error(res.error); return; }
    data = res.data || [];
    render();
  }

  // ── Rendering ─────────────────────────────────────────
  function render() {
    var container = document.getElementById('content');
    container.innerHTML = data.map(function (job) {
      return '<div class="job-card">' + escHtml(job.full_name) + '</div>';
    }).join('');
  }

  // ── API calls ─────────────────────────────────────────
  async function callApi(path, body) {
    var sess = await MQ.supabase.auth.getSession();
    var jwt = sess.data && sess.data.session && sess.data.session.access_token;
    var res = await fetch(path, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json', 'Authorization': 'Bearer ' + jwt },
      body: JSON.stringify(body),
    });
    return res.json();
  }

  // ── Entrypoint ────────────────────────────────────────
  document.addEventListener('mq:ready', function () {
    load();

    // Realtime (if needed)
    MQ.supabase
      .channel('my-page-realtime')
      .on('postgres_changes', { event: '*', schema: 'public', table: 'quote_requests' },
        function () { load(); })
      .subscribe();
  });

  // Handle bfcache restore
  document.addEventListener('mq:pageshow', function () { load(); });

})();
