MyQuest Developer Wiki

Internal technical reference for the MyQuest cleaning business management platform. This wiki covers the full stack — public site, internal dashboard, API functions, database schema, and operational concerns. It is offline-only and not publicly hosted.

What is MyQuest?

MyQuest is a SaaS platform for cleaning businesses. It provides a public marketing site with online quoting, and a private dashboard for staff, managers, and owners to manage jobs, clients, rosters, training, and business settings.

The platform is deliberately simple in its tech stack — no frontend framework, no build step, no bundler. Everything is plain HTML, CSS, and vanilla JS, deployed to Cloudflare Pages. Backend logic lives in Cloudflare Functions (Workers). Data is stored in Supabase (PostgreSQL + Auth + Storage).

VariableUsed byNotes
